## Integration and intentional differences

The new `.agents/skill-capabilities.json` records intended runtime coverage, source owners, entrypoints, required tools/resources, shared contracts, justified exceptions and retired routes. `check-skill-capabilities.mjs` checks missing coverage, local resources, ownership drift and retired entrypoints. It generates the human catalog in [Codex skill maintenance](../codex-skills.md), which includes every declared runtime exception. Explicit local disables remain supported without erasing intended coverage.

Runtime dispatch, history paths, client discovery and authentication remain runtime-specific. Codex addskill uses built-in skill-creator; Claude uses packaged authoring guidance. A Codex reviewer of Codex work can have fresh context while sharing the author vendor. CLI review requires observed authentication/model behavior. Both merge bodies now use task branches and guarded verification; the earlier direct-main difference was removed.

AGENTS.md routes authoring and manifest validation. CLAUDE.md replaces its duplicate style digest with a thin Caveman/Writing route and explicit user-voice precedence. Provenance records material fork changes and retained licenses. The local plugin version changes from 1.4.0 to 1.5.0 for the added Claude capability; no release is published. README inventory replaces writing-skills with perf-loop in Quality disciplines and regenerates README.md plus all 16 SVG variants.
