# Project knowledge

Resolve the knowledge store from AGENTS.md and the project's reference index. Existing .claude/reference files are valid shared data; using them does not import Claude runtime behavior. Search relevant topics before opening whole libraries.

Lookup: read the matching entries, verify anything likely stale against current files, and cite the source. Say when nothing relevant exists. Do not invent remembered facts.

Save: when authorized to remember a durable learning, edit the narrowest existing topic. Record a short dated symptom, cause or fix, evidence and any limit. Replace a stale entry rather than accumulating contradictory advice. Add an index link only for a new topic. Never store credentials or private transcript dumps.

Distinguish a one-off observation from a standing preference. An attention failure does not require another copy of an existing rule. Generic lessons may warrant a separate proposed starter change; do not silently edit another checkout. Saving a reference does not authorize committing, pushing or syncing it. Report exactly what was saved or proposed.
